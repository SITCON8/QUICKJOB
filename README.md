# QUICKJOB — prototype public

Cette version est une vitrine responsive en HTML/CSS/JavaScript, sans dépendances.

**Important :** les trois offres sont fictives. Connexion, comptes, dépôt de CV, candidatures et espace recruteur ne sont pas encore reliés à un serveur. Ne collectez aucune donnée personnelle avec ce prototype.

## Publier gratuitement avec GitHub Pages
1. Ajoutez `index.html`, `styles.css` et `app.js` à la racine du dépôt GitHub `QUICKJOB`.
2. Ouvrez **Settings → Pages** dans le dépôt.
3. Sous **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez `main` et `/ (root)`, puis **Save**.
5. Après le déploiement, le lien sera `https://VOTRE-PSEUDO.github.io/QUICKJOB/`.
